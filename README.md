# Drive Mad 本地复刻（前八关）

需要 Node.js 18 或更高版本；游戏所需浏览器依赖随项目本地提供，无需执行 `npm install`。

双击 `启动游戏.cmd` 即可启动本地网页并打开游戏；也可以在此目录运行 `npm start`，然后访问 <http://127.0.0.1:4188>。若端口被占用，可先运行 `set PORT=4189`（PowerShell 使用 `$env:PORT=4189`）更换端口。

进入后先显示动态主菜单，可选择第一至第八关。第一至第三关沿用原有游戏逻辑；第四关“Ascending Planks”先经过明显的大上坡和高速下坡，再通过十三块逐级升高、各自独立悬挂的长木板。第三块木板已删除，其位置由一段更长的固定上坡陆地连接第二块和第四块木板；其余木板之间的陆地也是连续向上斜面。第一块木板前设置持续向上喷气的黄色助推装置，喷口包含三层火焰和持续上升的喷气粒子。赛道沿线设置四块自动旋转的实体挡板，越往后转速越快；第一块顺时针旋转，从第二块开始全部反向旋转，最后一块转速最快。每块旋转挡板两端带有随动喷气尾焰。到达末端区域后车辆会从最高木板落到下方低地，再从最后一块挡板的下方驶过，终点位于挡板后方更远的位置。每块木板只有约 ±3.4° 的轻微摆动，不会自由翻转；车顶碰到地面、木板或其他实体时会和所有关卡一样直接失败。赛道使用普通实体地面和普通车轮物理，没有轨道锁定或位置瞬移。镜头在任意高度都会持续跟随车辆上下移动。第五关“Jet Gates”是新增的喷气飞行过渡关：车辆沿用喷气隧道原始的飞行推进逻辑，不额外增加空中姿态稳定；赛道缩短为一条平直跑道，中途连续矗立三道带洞口的墙，必须依次从三个墙洞中飞过才能到达终点：三道洞口都只有原始高度的一半，分列在墙面的中、下、上三个高度，中间的贴地、最后的贴着顶板，头顶设有不致命的顶部挡板，防止直接飞越墙体。第六关“Jet Lift”只保留第五关中间那道墙（贴地洞口缩为一半、净高 2.325 米），其余位置全部改成活动机关：第一道墙被拆除，换成一台三片扇叶的大风扇转盘；最后一堵墙位置改成两台上下移动的墙，一前一后、速度相同、从两端相向起步，因此永远一升一降、方向相反；后面再加一台四片扇叶、尺寸大幅加大且转速更快的风扇转盘（叶片长 7、厚 0.85，位置后移到 x=60）。为了给这台大风扇留出空间，赛道终点由 64 米延长到 70 米。中间那道墙下方仍保留喷气装置（中心在墙右侧 0.5 米、推力 180、宽 1.7、柱高 6.05）。另外，第六关的顶部挡板已由安全顶板改为普通天花板：车顶碰到天花板、或碰到任何风扇转盘的轴心，都会直接判定失败；扇叶本身仍然只是把车推开，不会致死。注意：新加的第一台活动墙距离贴地出口只有 6 米，当前参数下这一关会被卡死（见下）。第七关是原来的喷气隧道；第八关是原来的巨型齿轮关卡，包含三连转盘、探测器、二十五秒红外激光和左下角实体木箱。第八关所有巨型转盘的扇叶黄色装饰条均已移除，中央支撑柱保持半透明；不同高度的顶部安全天花板已全部封闭并延伸到终点。主菜单选关面板下方提供五种可选车身颜色，并会记住上次选择；已经通关的关卡会在卡片右下角显示一个绿色对勾，通关记录保存在浏览器本地，下次打开仍然可见；第七关和第八关的卡片右上角带有红色“高难度”标签。按关卡卡片或“开始第 N 关”进入赛道。操作方式：方向键或 `A`/`D` 控制油门与倒车，`R` 重新开始，`P` 暂停，`F` 切换全屏。暂停后可继续、重新开始或返回主菜单。

前三关使用本地重建的画面和物理逻辑，车辆驱动已增强；第一关现已扩展为五段跨海飞坡赛道，需要利用每段上坡积累的速度越过逐渐加宽的海面缺口。不包含官方源代码，也不代表与原版实现或素材完全一致。

当前车辆为后轮驱动：只有后轴接收马达输入，前轮不施加驱动力并自由滚动；马达速度与扭矩已进一步提升。第三关按住前进键会自动启动火箭推进器，右下角图标只作为推进状态指示。

当前通关规则：车辆车身右侧或任一车轮进入终点区域即可通关，空中穿过终点也有效。

终点判定现在只覆盖终点门洞高度，门顶上方不计入终点区域；车辆在门洞内或门洞高度范围内飞过终点线即可通关。
